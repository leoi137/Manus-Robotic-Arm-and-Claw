## Executive summary
Vendor the official SO-101 URDF + STL meshes from TheRobotStudio/SO-ARM100 (the exact model the Amazon unit is printed from), convert to USD with Isaac Lab's `scripts/tools/convert_urdf.py`, and wrap it in a small `manus` Python package: an `ArticulationCfg` with `ImplicitActuatorCfg` gains/limits derived from the Feetech STS3215 servo spec, an `InteractiveSceneCfg` scene (ground + light + arm), and a `CameraCfg` rigidly attached to the gripper/wrist link for the claw's POV. Control is plain joint-position targets — no AI/RL. Sim joint names mirror LeRobot/Feetech motor names so the same control code later drives the physical arm. Everything runs via the existing `~/isaaclab-env` Python; no new heavyweight deps.
